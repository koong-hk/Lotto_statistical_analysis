### 로또 통계 분석 Pro

#### 포함 파일
- `app.py`: Streamlit 대시보드, 통계, 추천 조합 생성, 워크포워드 백테스트, 데이터 검증
- `update_job.py`: 작업 스케줄러/cron에서 실행할 업데이트 스크립트
- `requirements.txt`: 필수 라이브러리
- `data/`: 실행 시 CSV 및 업데이트 로그가 생성되는 폴더

#### 실행 방법
Python 3.10 이상 권장

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

설치 및 실행:
```bash
pip install -r requirements.txt
streamlit run app.py
```

앱 왼쪽의 `데이터 가져오기 / 업데이트` 버튼을 눌러 처음 데이터를 수집합니다. 인터넷 연결과 동행복권 공개 API 접근이 필요합니다.

#### 보강 기능
1. 최근 4주/8주/전체 번호 빈도 및 그래프
2. 홀짝·5개 구간 분포 시각화
3. 연속번호 및 직전 회차 공통번호 통계
4. 동일한 3개 번호 조합이 3회 이상 함께 나온 회차 검색
5. 최근 빈도·전체 빈도·미출현 기간 가중치 조절
6. 사용자 지정 번호 가중치
7. 홀짝·합계·구간 수·연속번호·필수/제외 번호 필터
8. 추천 CSV 다운로드
9. 워크포워드 백테스트: 각 과거 회차 이전 데이터로만 추천 생성
10. 회차 누락/번호 오류 검증 및 업데이트 로그
11. 주간 자동 업데이트용 스크립트

#### 주간 자동 업데이트
##### Windows
작업 스케줄러에서 주간 작업을 등록합니다. 프로그램에는 `python` 실행 파일 경로, 인수에는 `update_job.py`의 전체 경로, 시작 위치에는 프로젝트 폴더를 지정합니다. PC가 꺼져 있으면 실행되지 않을 수 있습니다.

##### macOS/Linux cron 예시
```cron
15 22 * * 6 cd /path/to/lotto_streamlit_app && .venv/bin/python update_job.py >> data/update_cron.log 2>&1
```
경로/시간을 환경에 맞게 변경하세요.

#### 유의사항
- 본번호 6개를 기본 분석 대상으로 사용하며 보너스 번호는 저장만 합니다.
- 직전 회차 중복은 연속한 두 회차의 본번호가 하나 이상 겹치는 경우입니다.
- 반복 3개 조합은 동일한 세 번호가 3회 이상 같은 회차에 함께 나온 경우입니다.
- 앱 실행만으로 자동 예약 업데이트가 되지 않습니다. 별도 작업 스케줄러 등록이 필요합니다.
- 로또는 무작위 추첨이며 통계와 가중치는 추천 규칙일 뿐 당첨 예측/보장이 아닙니다.


#### API 연결 오류 수정판
이 버전은 2026년 홈페이지 개편에 맞춰 새 `/lt645/` 조회 경로와 새 JSON 필드명을 사용합니다.
앱의 데이터·자동화 탭에서 **연결 테스트**를 눌러 응답 여부를 확인할 수 있습니다.
동행복권 사이트가 접속을 제한하거나 내부 조회 경로를 변경하면 다시 수정이 필요할 수 있습니다.
